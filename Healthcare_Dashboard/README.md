# 🏥 Healthcare Patient Analysis Dashboard

## Overview

This project demonstrates a Healthcare Analytics Dashboard developed using Business Intelligence techniques to analyze patient information, monitor KPIs, and generate actionable insights.

---

## Objectives

- Analyze patient demographics
- Monitor healthcare KPIs
- Track treatment performance
- Identify operational trends
- Improve reporting efficiency

---

## Dashboard Features

- Patient Summary
- Admission Analysis
- Gender Distribution
- Age Analysis
- Department Analysis
- Treatment Insights
- Interactive Filters
- KPI Cards
