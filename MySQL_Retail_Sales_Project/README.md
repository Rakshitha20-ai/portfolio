# Retail Sales Analysis using MySQL

## Project Overview
This project analyzes a large retail sales dataset using MySQL to identify business insights and improve decision-making.

## Dataset
- Retail & Warehouse Sales Dataset
- Records: 307,645+
- Database: MySQL 8.0

## Objectives
- Clean and validate the dataset
- Perform exploratory data analysis
- Analyze sales trends
- Identify top-performing suppliers and products
- Use advanced SQL techniques to generate business insights

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- CASE Statements
- JOINS
- Common Table Expressions (CTEs)
- Window Functions
- RANK()
- DENSE_RANK()
- ROW_NUMBER()
- LAG()
- LEAD()

## Key Insights
- Identified top-performing suppliers.
- Compared retail sales and warehouse sales.
- Analyzed yearly and monthly sales trends.
- Ranked products based on sales.
- Categorized suppliers into High, Medium, and Low sales groups.
